9. PARAMETROS ACTUAIS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  SLOT_DURATION_US = 50000   (50ms por slot)
  GUARD_US         = 5000    (5ms guard time)
  MAX_AGE          = 2.0s    (timeout de no)
  MISS_THRESHOLD   = 5       (misses consecutivos para degradar qualidade)
  num_nodes        = 3
  frame            = 3 x 50ms = 150ms

  No 1 = Raspberry AlphaBot  172.20.10.1  10.0.0.1
  No 2 = Raspberry Relay     172.20.10.2  10.0.0.2
  No 3 = PC Base Station     172.20.10.3  10.0.0.3

  Video ip_forward: UDP para 10.0.0.3:5000 via TUN + kernel ip_forward
  Video ARP trick:  UDP direto com ARP spoofing para relay

  Relay dispara apos: 5 slots x 150ms = ~750ms de perda continua
